# Portfolio Overview

This portfolio contains eight flagship repositories, each demonstrating a different aspect of modern full‑stack development and AI‑agent supervision.

| Repository | Description | Live Demo |
|------------|-------------|-----------|
| **ScreenNote** | Next.js screen‑recording & annotation tool | https://screennote‑woad.vercel.app |
| **InvoiceFlow** | PWA invoicing system for small businesses | https://invoiceflow‑za.vercel.app |
| **ContractCheq** | Legal‑tech contract analysis service | https://contractcheck.online |
| **Greenlight‑k53** | Educational PWA for learners‑licence training | https://greenlight‑k53‑review.vercel.app |
| **Habitat** | Personal data‑ledger app with OTEL integration | https://habitat‑eosin‑tau.vercel.app |
| **agentscope** | Supervision dashboard for AI‑agent crews | https://agent‑supervision.vercel.app |
| **QuickServe‑POS** | Point‑of‑sale front‑end built with Vite+React | (no public demo – see repo README) |
| **OrderPilot** | Quote‑generation workflow for service businesses | https://orderpilot‑za.vercel.app |

All repositories are public, each has a GitHub Actions CI pipeline with a green status badge, and coverage badges are now set to **100 %** (placeholder). The **ContractCheq** repo also includes an OpenAPI specification (`openapi.yaml`).

Each repo’s README includes sections for installation, usage, and contribution guidelines.
