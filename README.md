# Portfolio Overview

This repository contains a simple HTML page (`index.html`) that showcases the eight flagship projects of **buttercode101**. The page includes live‑demo links, coverage badges, and brief descriptions.

## GitHub Pages

The `gh-pages` branch has been created and contains the same `index.html`. Enable GitHub Pages in the repository settings (source: `gh-pages` branch, root) to serve the site at:

```
https://buttercode101.github.io/portfolio-overview/
```

You can also view the raw HTML directly in this repo.
